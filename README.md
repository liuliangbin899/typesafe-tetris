## 💡 1. 什么是 TypeSafe？它跟 ChatGPT 有什么本质不同？

想象你在打乒乓球或玩高难度动作游戏：
- ❌ **如果用传统大语言模型（如 ChatGPT / Claude）**：  
  当球飞过来时，它需要先在脑子里写一篇 500 字的论述题，然后一个词一个词往外吐（Token-by-Token）：“根据当前球的轨迹，我建议向左侧挥拍……”——**耗时几百毫秒甚至几秒，输出的内容还可能格式报错或产生幻觉，球早就落地砸脸了！** 这种机制叫 **System 2（慢思考系统）**。
- ✅ **如果用 TypeSafe (System One)**：  
  它就像职业运动员的**“肌肉反射与条件直觉”**。面对复杂局面，它不需要啰嗦写作文，而是直接输出经过概率计算的**确定性选择与直觉打分**：
  > “危险系数：`1.2%`（安全！）”  
  > “最佳落点：`方案 B`（胜率 85%）”  
  > **全程耗时只需 12 毫秒！** 输出结果是 **100% 强类型数学契约**，绝不可能发生解析崩溃！

> 📌 **核心公式**：  
> **传统大模型 = 聊天机器人（生成不可控的自然语言自由文本）**  
> **TypeSafe = 带有常识直觉的编程积木（生成数学确定性、毫秒级响应的类型安全概率）**

### 原语详解（人话版与代码对照）

#### ① `Noul` = 敏锐的“是非直觉警报器”
- **人话解释**：输入当前局势，问它一个是非问题，它直接返回真值置信度 $P \in [0.0, 1.0]$。
- **业务场景 1：危机门控 (`is_crisis_danger`)**  
  当棋盘堆叠过高或被空洞堵死时，$P(\text{Crisis}) \ge 50\%$ 瞬间警报拉响，强制让 AI 放弃贪大招，切换为防守求生。
- **业务场景 2：换块门控 (`should_hold`)**  
  当前方块实在无处安放时，直接给出置换信号，将其暂存到背包。

```python
# ai/typesafe_agent.py 中真实的原语调用定义
"is_crisis_danger": Noul(
    instructions="分析当前棋盘指标，最高行是否已超过12行或空洞过多？局面是否处于崩盘边缘？"
),
"should_hold": Noul(
    instructions="对比当前活动块与暂存背包中的方块，当前块是否极难落脚且换块明显更优？"
)
```

#### ② `Choice` = 不纠结的“单选题终结者”
- **人话解释**：在有限个选项集合中，为每一个选项计算 Softmax 胜出概率，并精准选出置信度最高的一个。
- **业务场景 1：战术分类 (`tactic_mode`)**  
  在“紧急避险”、“填平底盘”、“蓄积深井Tetris”、“连击冲分”之间动态分配权重。
- **业务场景 2：候选落点竞争 (`selected_candidate_id`)**  
  物理引擎事先生成所有无碰撞落点（带着消几行、增几个洞、高度差等数据），`Choice` 直接给出每个落点的胜算概率，胜出方案实时在 Web 上投影出青色虚线框。

```python
# 从候选项集合中精准选出最优解
"selected_candidate_id": Choice(
    instructions="根据当前战术模式，从 candidates 备选落点中挑出综合收益最高、最稳妥的方案",
    criteria={cand.id: cand.to_summary() for cand in candidates}
)
```

#### ③ `Score` = 有远见的“1~5 星态势裁判”
- **人话解释**：避免 AI 只顾眼前利益（短视），对局面未来的可持续健康度进行 1~5 级离散评级。
- **业务场景 (`board_health`)**：  
  即使一个落点能立刻消除 1 行，但如果导致未来健康度断崖跌入 1 级（垃圾空洞覆盖），AI 通过 `Score` 的全量概率分布即可预先规避。

```python
# 5 级离散健康态势评级
"board_health": Score(
    instructions="评估当前棋盘的整体健康度与可持续发展态势 (1~5 级)",
    criteria=[
        "1: 濒危崩盘，高度触顶，空洞严重阻塞通道",
        "2: 态势不良，凹凸差距大，需要多次复杂清坑",
        "3: 正常态势，高度适中，具备基本的消行空间",
        "4: 良好态势，表面平整无隐患，易于连续消行",
        "5: 黄金态势，底盘平实扎实，深井整齐，攻守兼备",
    ]
)
```

│ • 分数/行数/等级 │ • AI 落点虚线投影│ • 组装 Context State 树 │ • 危机与换块 Noul 仪表  │

   在第 4 栏中，实时展示各候选落点的横向概率条、宏观战术分布圆盘与危机避险门控标尺。
3. **实时推理耗时与三档动作调速**：
   - 顶栏与看板高亮展示 TypeSafe 的推理延迟（`12.5ms` 极速）；
   - 顶栏提供 `🐢 慢速 (120ms)`、`⚡ 标准 (40ms)`、`🚀 极速 (10ms)` 动作巡航步频切换。

## 🕹️ 5. 交互与控制说明

游戏支持 **全自动驾驶** 与 **人类手动操控** 双模平滑协作：

- **鼠标操控**：主棋盘正下方提供 **【🎮 屏幕手动控制台】**，鼠标点击方向键、旋转、硬降、暂存即可直接玩；
- **键盘操控**：
  - **`M` 或 `A`**：随时在 **AI 自动驾驶** 与 **人类手动操控** 之间无缝切换；
  - **`Q`**：快速轮换策略意图（“稳扎稳打”、“组织大招”、“消行冲刺”、“绝境求生”）；
  - **`←` / `→` / `↓`**：左右平移与加速软降；
  - **`↑` 或 `X`**：顺时针 SRS 踢墙旋转；**`Z`**：逆时针旋转；
  - **`空格`**：瞬间硬降触底锁定；
  - **`C`**：暂存当前方块 (Hold)；**`P`**：暂停/继续；**`R`**：重新开始。

> **💡 人机协同亮点**：在人类手动操作时，AI 大脑依然会在后台全速运转，并在棋盘上实时画出青色虚线框，为您提供最佳落点参考！
